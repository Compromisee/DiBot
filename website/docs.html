Overview

DiBot is a fully-featured, production-ready Discord bot built with discord.py 2.3.2. It supports both prefix commands (!) and slash commands (/), includes a web dashboard powered by Quart, and uses SQLite for persistent data storage.

lightbulb
94+ features included out of the box. No premium tiers, no paywalls, no missing functionality. Deploy once and everything works.

Installation

1. Clone the Repository

bash

source venv/bin/activate

python -m venv venv
venv\Scripts\activate

vpn_key

Getting Your Bot Token

  1. Go to discord.com/developers/applications
  2. Click New Application and give it a name
  3. Navigate to the Bot tab
  4. Click Add Bot then Reset Token
  5. Copy the token and paste into DISCORD_TOKEN in your .env
error
Never share your bot token. If leaked, immediately reset it in the Developer Portal.

Required Intents

Enable these in the Bot tab of the Developer Portal:

dashboard

Dashboard Setup

  1. In Developer Portal, go to OAuth2 tab
  2. Click Reset Secret and copy it to CLIENT_SECRET
  3. Under Redirects, add: http://localhost:5000/callback
  4. Set REDIRECT_URI in .env to the same URL
  5. The dashboard starts automatically with the bot
lightbulb
The dashboard runs on http://localhost:5000 by default. Change DASHBOARD_PORT to use a different port.

FAQ

Check that Message Content Intent is enabled in the Developer Portal. Verify the bot has permissions in the channel and your prefix matches the one in .env.

Install FFmpeg and ensure it's in your system PATH. Run ffmpeg -version to verify. Also ensure yt-dlp and PyNaCl are installed.

In Developer Portal, ensure the redirect URL http://localhost:5000/callback is added under OAuth2 Redirects. Make sure CLIENT_ID, CLIENT_SECRET, and REDIRECT_URI match exactly.

Global slash commands can take up to 1 hour to sync. Ensure the bot invite URL includes the applications.commands scope.

The bot's role must be higher than the target member's highest role. Check role hierarchy in Server Settings.
