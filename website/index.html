rocket_launch Quick Start

Deploy in 4 steps.

01

download Clone

Clone the repository from GitHub to your local machine.

git clone https://github.com/Compromisee/DiBot.git
02

package_2 Install

Install all Python dependencies with pip.

pip install -r requirements.txt
03

key Configure

Copy the example env file and add your bot token.

cp .env.example .env
04

bolt Launch

Start the bot and dashboard with one command.

python bot.py
